# Procedência histórica — classificação superada

Cópias físicas integrais, verificadas por SHA-256, do registro encontrado em outra raiz local, conforme `manifest.json`. Os originais não foram movidos ou alterados. A cópia do registro SIM01 contém a classificação anterior de ensaio fictício; **essa classificação foi corrigida pelo esclarecimento expresso do usuário: trata-se de P01, uma pessoa humana real, com respostas posteriormente revisadas**. O texto preservado é evidência documental da origem, não a classificação atual.

Registro canônico: [P01](../P01.md). Não usar as aspas antigas como transcrição literal, nem as conclusões antigas N=0 como estado atual. Os arquivos de estado/captura associados documentam automação; não comprovam autoria humana dos cliques, consentimento, idade, tempo ou primeira exposição independente além do relato informado.

O arquivo STATUS preservado também descreve reservas em branco e N=0 naquele contexto de preparação. Reservas P02–P05 não são sessões e não serão recrutadas no escopo revisado. As folhas reservadas não foram importadas como resultados.
