# Figuras científicas exportáveis

PNG de 180 dpi e SVG vetorial, com dados de suporte em CSV. Sem inferência causal ou rótulos de quadrante. Imagens revisadas visualmente como artefatos científicos; nenhuma nova auditoria visual do site.

1. [Composição](01_distribution.png) · [SVG](01_distribution.svg): todos os dropbacks, incluindo outras posições, denominador explícito por ano.
2. [Progressão × improvisação](02_progression_vs_improvisation.png) · [SVG](02_progression_vs_improvisation.svg): X=B, Y=A em EPA/jogada, nomes e n identificados por número; liga de todos os QB e diagonal de diferença zero. [Suporte](scatter_support.csv).
3. [Frequência × produção](03_frequency_vs_production.png) · [SVG](03_frequency_vs_production.svg): frequência sobre todos os dropbacks do jogador, mesmo conjunto principal de 15 QB.
4. [Sensibilidades](04_sensitivity.png) · [SVG](04_sensitivity.svg): mesma coorte, quatro definições, n de cada B junto ao nome. S3 quase sempre abaixo do corte em 2026. [Suporte](sensitivity_support.csv).
5. [História](05_historical.png) · [SVG](05_historical.svg): temporadas separadas, todos os QB com pelo menos duas temporadas legíveis; traço é ausência/baixo suporte, não zero. [Níveis e volumes completos](historical_support.csv).

Omitidos das figuras principais permanecem nas [tabelas completas](../tables/comparisons.csv). Corte: A≥100, B≥25 EPA válidos e ≥5 jogos A/B; legibilidade, sem garantia de robustez. `DES` é residual conhecido, não charting ausente. Fonte: PBP nflverse e FTN Data via nflverse, dados transformados CC BY-SA 4.0, sem endosso.
